# Kennel One 2.8 screenshot-based marketing previews

Three nine-second, vertical, silent MP4 preview clips made from real Build 128 App Store screenshots:

1. Dogs and Litters
2. Daily Care and Calendar
3. Smart Kennel QR and NFC

These are **social-media marketing previews only**, not Apple App Preview screen recordings. They use still screenshots with fades and labels, not simulated user interaction. Do not submit to Apple's App Preview gallery as demonstrations without recording actual app use. They deliberately do not claim Kennel One 2.8 is already publicly released. Build 129 includes later iPhone dashboard refinements, which were not present in the original Build 128 screenshot set.

Local editable/render source on the owner's Mac: `~/Developer/kennelflow_make_previews.py`. Save that script independently when editing.
